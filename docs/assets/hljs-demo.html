Raw Inline & Block

Inline raw: `<span style="color:red">red text</span>`{=html}

Block raw HTML:

``` =html
<div class="alert alert-info">
  <strong>Note:</strong> This is raw HTML!
</div>
```

Also works for LaTeX: `\textbf{bold}`{=latex}
